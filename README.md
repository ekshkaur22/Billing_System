# Billing Management System

## 📌 Project Overview
The **Billing Management System** is a desktop application developed using Python and Tkinter. It helps manage customer billing by calculating product prices, taxes, and the final bill amount. The application includes three product categories: Medical Products, Grocery Items, and Cold Drinks.

It provides a simple graphical user interface (GUI) to make billing operations easy, organized, and efficient.

## ✨ Features
- **Customer Details:** Enter customer name and 10-digit phone number.
- **Product Management:** Select quantities of medical products, grocery items, and cold drinks.
- **Automatic Price Calculation:** Calculate the total price for each product category.
- **Tax Calculation:** Automatically calculate taxes for different product categories.
- **Bill Generation:** Generate detailed bills with customer information, products, quantities, prices, taxes, and the final amount.
- **Save Bill:** Save generated bills as text files.
- **Search Bill:** Retrieve previously saved bills using the bill number.
- **Clear Data:** Reset customer details, product quantities, and billing information.
- **Exit Option:** Close the application with a confirmation prompt.

## 🛠️ Technologies Used
- **Programming Language:** Python
- **GUI Framework:** Tkinter
- **Modules:** `random`, `os`, `tkinter.messagebox`
